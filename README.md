# Deyu — website

Website and privacy policy for **Deyu** — a small, private Android journaling app:
one true sentence a day, kept as stars in a jar, all stored locally on your phone.

- `index.html` — landing page
- `privacy-policy.html` — privacy policy
- `fr/index.html`, `fr/privacy-policy.html` — the same two pages in French
- `assets/` — page images

Published with GitHub Pages → https://deyustars.github.io/
